# Reusable study skills

These are small, provider-neutral Markdown instruction packages for using an AI tool as a DSA learning coach. Each folder is self-contained and can be copied or linked into the skills directory supported by the tool you use.

Available invocations:

- `/dsa-explain` - explain one topic for a beginner without skipping the invariant.
- `/dsa-trace` - generate a paper-first state trace before code.
- `/dsa-coach` - give one hint at a time and protect the learner's opportunity to solve.

Each package declares its name, purpose, prerequisites, and invocation name in `SKILL.md`.
